# 07 収益化 — アフィリエイト / AdSense

## 全体方針
- 収益導線は**データページに文脈連動で置く**。ポップアップ・本文偽装はしない（AdSense審査・UX両面）。
- アフィリエイトリンクは全て `src/lib/affiliates.ts` の定数経由（ASP変更時に一括差替できるように）。リンクには `rel="sponsored noopener"`。
- 記事にはPR表記（景表法ステマ規制対応）: アフィリエイトリンクを含むページ先頭に「本ページにはプロモーションが含まれます」を共通コンポーネントで表示。

## 導線マップ
| 場所 | 商材 | 実装 |
|---|---|---|
| 試合結果・日程ページ | DAZN（リーグワン）、スカパー/J SPORTS（Top14等) | 「この試合を見る」ボタン。リーグ→視聴サービス対応表を `affiliates.ts` に定義 |
| 海外リーグページ | 視聴方法ガイド記事へ内部リンク | 下記「視聴ガイド」 |
| 選手ページ（ポジション別） | スパイク・プロテイン | ポジション→商品カテゴリ対応（FW=スクラム向けスパイク等）。Amazon/楽天 |
| 代表戦・リーグワン試合ページ | 会場周辺の宿泊（楽天トラベル/じゃらん） | matchのvenueから会場→エリアの対応表 `data/manual/venue_areas.json` を引く |
| RWC2027特集 | 豪州航空券・ホテル・ツアー | 特集ページを1本、静的に作成（開催都市別ガイド） |

## 視聴ガイド記事（「日本で見る方法」）
- リーグごとに1本: 「Top14を日本で見る方法」「Super Rugby Pacificを〜」等
- 内容は **正規の視聴手段を優先**: 国内放映権（J SPORTS等）、公式配信サービスの順に紹介
- VPN利用の紹介をする場合の注意（必読）: VPN自体の利用は日本では合法だが、**配信サービスの地域制限回避は各サービスの利用規約違反になり得る**。記事では「規約はご自身で確認を」の注意書きを必ず入れ、「規制回避の手順書」ではなく「海外在住者・出張者向けのVPN紹介」というトーンにする。ASPはVPN案件（NordVPN等）が一般的
- この判断はグレーゾーンを含むため、**記事公開前にユーザー確認を1回挟む**（draft: true で作成→ユーザーがレビュー）

## AdSense
- 自動広告は使わず、手動配置: 記事本文中1、選手ページ下部1、一覧ページ中間1
- 審査対策: 監査(03)で draft 化した低品質記事が公開されていない状態で申請。プライバシーポリシーに広告・計測の記載を追加（既存 privacy.astro を更新）

## 実装順（P4）
1. `affiliates.ts` + PR表記コンポーネント + 「この試合を見る」ボタン（DAZN/スカパー）
2. venue_areas.json + 宿泊導線
3. 視聴ガイド記事（draft）→ ユーザーレビュー → 公開
4. RWC2027特集
5. 物販（スパイク/プロテイン）はASP審査が通ってから

- PR表記が該当全ページに出る
