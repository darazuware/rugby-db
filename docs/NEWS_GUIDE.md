# RUGBY PICKS ニュース記事作成ガイド

「ニュース & コラム」セクションに記事を追加する方法と、AdSense合格・SEOのためのポイントをまとめました。

## 1. 記事ファイルの作成方法

### ① ファイルの配置場所
`src/content/news/` ディレクトリの中に、新しい Markdown ファイル（`.md`）を作成してください。

### ② ファイル名のルール
半角英数字とハイフンのみを使用してください。
- **良い例**: `league-one-2026-preview.md`
- **悪い例**: `2026プレビュー.md` (日本語不可)

### ③ フロントマター（ヘッダー情報）
ファイルの冒頭に、以下のテンプレートをコピーして、内容を書き換えてください。

```markdown
---
title: "ここがタイトル（記事の見出し）になります"
description: "記事の要約です。Googleの検索結果にも表示される重要な部分です。"
pubDate: 2026-03-24
category: "COLUMN" # "NEWS" または "COLUMN"
tags: ["リーグワン", "日本代表", "移籍情報"]
---

ここから記事の本文を Markdown 形式で書き始めます。
```

## 2. AdSense合格 & SEO のための最強ライティング術

Google は「独自性（オリジナリティ）」と「専門性（EEAT）」を非常に重視します。

### ① 「自分にしか書けない視点」を加える
単なるニュースの要約ではなく、**「ラグビーファンとしての熱量あるコメント」**を必ず1段落以上入れましょう。
- **NG**: 「パナソニックがサントリーに勝利しました。」 (どこにでもある情報)
- **OK**: 「パナソニックの堅守は、昨シーズンの第5節のあの時を彷彿とさせました。特に〇〇選手のタックルは、統計データ以上に試合の流れを変える力があります。」 (独自の分析)

### ② キーワードを自然に盛り込む
- **タイトルの左側**: 検索されやすい単語（例：選手名、チーム名、大会名）をタイトルの最初の方に配置します。
- **見出し（H2, H3）の活用**: 本文を `## 注目ポイント` や `## 試合の感想` といった見出しで区切り、読みやすくします。

### ③ 内部リンクで「専門サイト」であることをアピール
- 記事内で選手名が出てきたら、その選手の詳細ページ（`/players/slug/`）へのリンクを積極的に貼りましょう。
- これにより「このサイトはラグビーに関する情報が網羅されている」と Google に評価されやすくなります。

### ④ 画像や表を活用する
- 必要に応じて Markdown の表構文を使用してスタッツをまとめたりすると、コンテンツの質が上がります。

## 3. 記事公開の流れ

1. **ローカルで確認**: `npm run dev` を実行し、`http://localhost:4321/news/` で自分の記事が表示されているか確認します。
2. **プッシュ**: 
   ```bash
   git add .
   git commit -m "feat: new article about [記事のトピック]"
   git push origin main
   ```
   これで、本番サイトに自動的に反映されます。
