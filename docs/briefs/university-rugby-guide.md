## 守るルール（必須）
- **事実をAIの知識で書かない。** 日程・出場枠・会場・放送は、必ず公式ページ（JRFU、各協会、大学選手権の公式、J SPORTS・NHKの公式）をWeb検索で確認して書く。確認できない項目は書かない、または「未発表」とする。

- 他サイトの文章を流用しない。自分の言葉で構成する。
- frontmatter は既存の `src/content/news/*.md` に倣う（title / description / pubDate / category: "GUIDE" か "COLUMN" / tags）。
- 書き終えたら `python3.11 scripts/link_news.py --write` で内部リンクを付け、事実誤りがないか再点検してから公開（draft: false）。
- `data/master/` は編集禁止。
- 大きな日程変更が起きうるので、pubDate/updatedDate と「データ基準日」を明記。
