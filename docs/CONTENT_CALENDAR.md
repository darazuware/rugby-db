## 運用ルール
- **週2本**（火・金）を基本。1日に3本以上まとめて公開しない。
- `pubDate` は実際に公開した日を入れる。過去日への一括バックデート禁止。
- 日本代表の試合がある週は、試合翌日に必ず1本（速報レビュー）。
- 事実（スコア・選手名・日程）は必ず一次情報で確認する。AIの知識で書かない（`docs/renewal/03_VALIDATION.md`）。
  - 一次情報：日本ラグビーフットボール協会 `rugby-japan.jp` / 各リーグ公式
- 内部リンクを最低3本（選手名鑑・関連記事）。

## 試合翌日レビューのテンプレ手順
1. `rugby-japan.jp` の試合結果ページでスコア・前後半・会場・観客数を確認
2. ラグビーリパブリック等で得点者・試合の流れを補強
3. 選手名は `data/master/players/*.json` の slug と突き合わせて内部リンク化
4. 既存の代表記事（総括・日程・大会ガイド）へ相互リンク
5. `npm run build` で生成確認 → コミット
