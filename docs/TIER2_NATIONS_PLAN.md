# ティア2／ラグビー発展途上国 記事クラスタ計画

策定日: 2026-07-21

## ねらい
RWC2027（オーストラリア／**24チーム制**・52試合、4チーム×6プール）に向けて、強豪国以外の「情報が薄い国」を
**事実の細かさ**で差別化する。日本語圏でこの粒度（選手の所属クラブ・本業・国内リーグ構造・協会財政）
を書いているメディアはほぼ無い＝ロングテールSEOで取りやすい。

## 構造（ハブ&スポーク＋周回リンク）

```
[ハブ] tier2-nations-guide  ラグビー「第2グループ」ガイド
   ├─ zimbabwe-rugby-2026        ジンバブエ

   ├─ hong-kong-china-rugby-2026 香港チャイナ
```

### リンク規則（「グルグル回す」実装ルール）
1. **ハブ → 全スポーク**：ハブ記事の各国セクション末尾に「▶ 詳細記事」リンク。
2. **スポーク → ハブ**：各国記事の冒頭リード直後と末尾の2箇所にハブへのリンク。
3. **スポーク → スポーク（横リンク）**：各国記事末尾の「関連する国」で **同じ予選ルート／同大会で当たる2〜3カ国** へリンク。
   - ルーマニア ⇄ ポルトガル ⇄ スペイン（Rugby Europe 圏、同じ予選を戦う3カ国）
   - カナダ ⇄ アメリカ ⇄ チリ（アメリカ大陸枠）／ カナダ ⇄ アメリカ ⇄ 香港チャイナ（PNC）
   - ジンバブエ ⇄ ポルトガル（アフリカ枠 ⇄ 直近W杯の躍進組として「新興国の伸び方」で対比）
4. **既存記事への縦リンク**：`rugby-world-cup-2027-guide` / `japan-2026-fixtures` /
   `nations-championship-2026-guide` へ各記事から最低1本。
5. **選手名鑑への内部リンク**：所属選手が `data/master/players/*.json` に存在する場合のみ
   slug 突き合わせでリンク（存在しない選手は**リンクを作らない**）。

## 各国記事の共通テンプレ（見出し固定＝比較可能にする）
1. リード（なぜ今この国か。1〜2段落）
2. 基本データ表（World Rugbyランキング／協会設立／登録競技者数／愛称／主戦場）
3. RWC2027 出場権の状況（予選ルート・決定日・過去出場歴）
4. **注目選手**（表：氏名／ポジション／所属クラブ（国・リーグ）／年齢／キャップ）
5. **プロか、兼業か** — 選手の本業・契約形態・国内リーグのプロ化度
6. 国内リーグと育成の構造
7. 協会の台所事情と課題
8. 日本との関係（対戦歴・日本でプレーした選手）
9. どこで観られるか
10. 関連記事（ハブ＋横リンク）

## 事実の扱い（`docs/renewal/03_VALIDATION.md` 準拠）
- 選手・スコア・日程・所属は **一次情報で確認したものだけ**書く。AIの知識で書かない。
- 許容する一次情報：`world.rugby` / 各国協会公式 / `rugbyworldcup.com` /
  `rugbyeurope.eu` / `asiarugby.com` / `majorleaguerugby.com` / 各クラブ公式。
- 確認できなかった項目は**書かない**（「不明」とも書かず、その行ごと落とす）。
- ランキング・キャップ数は **取得日を本文に明記**（例「2026年7月時点」）。
- 記事末尾に「主な参照先」として公式サイトのリンクを列挙。

## 選手個人データの掘り方（生年・キャップ数・本業）
この3項目こそが差別化の中身。「World Rugby公式に無い＝不明」で止めず、以下を**全部**当たる。

| 欲しい値 | 当たる順番 |
|:---|:---|
| 生年月日・身長体重 | ① `all.rugby/player/...` の個別選手ページ ② **所属クラブ公式の選手ページ**（欧州クラブはほぼ必ず記載） ③ **LNR公式**（lnr.fr、Top14/Pro D2の全選手DB） ④ MLR公式 ⑤ ESPN Scrum ⑥ 各言語版Wikipedia ⑦ 協会SNSの誕生日投稿 |
| 代表キャップ数 | ① 協会公式のマッチデー発表（「◯キャップ目」と書かれる） ② all.rugby ③ ESPN Scrum ④ 現地メディアの節目報道（50キャップ達成など） |
| **本業・学業** | ① **現地メディアの選手インタビュー**（母国語で検索。ここに一番出る） ② 協会/クラブの選手紹介記事・YouTube紹介動画 ③ 大学・勤務先の広報記事 ④ 選手本人の公開SNSプロフィール |

- 母国語で検索する（西語・葡語・仏語・ルーマニア語・繁体中文）。英語だけだと本業の話は出てこない。
- **私生活は集めない**。競技経歴と、本人が公の場で語った職業・学業だけ。
- 値が食い違う場合は公式性の高い方を採り、記事には取得日を添える。
- それでも取れなければ、表の該当セルを「—」にする（**推測で埋めない**）。

## カタカナ表記（SEO）
日本語で「ジンバブエ ラグビー 選手」と検索する人は原語綴りでは探さない。**カタカナは検索の入口**。
- 選手名・クラブ名・愛称は**必ずカタカナを併記**する（表なら「カタカナ」列を作る）。
- 一度決めた表記は変えない。表記ゆれはSEOで最も損をする。
- カタカナ化はLLMで作ってよい（`docs/renewal/03_VALIDATION.md` の name_kana 運用と同じ扱い）。
  ただし**事実（所属・数字）はカタカナ化と切り離して一次情報から取る**。
- 愛称は原語＋意味を書く（例: ロス・コンドレス（禿鷹）、ステジャリー（樫の木）、オス・ロボス（狼））。
- 選手名鑑に同一人物がいる場合は、名鑑側の表記に合わせる。
