# 一次情報ファクトシート — ルーマニア（調査日 2026-07-22）

## 基本
- 愛称 Stejarii（樫の木たち／The Oaks）／HC **David Gérard**（仏、2024年から）
- ランキング **21位・62.45pt**（2026-07-20）。**最高位13位（2003-2006年）**
- RWC2027 出場権獲得済み（欧州枠）。**通算10回目**。**プールB**＝南アフリカ／イタリア／ジョージア
- 国内リーグ **Liga Națională de Rugby**

## W杯出場歴
- **9回出場**: 1987, 1991, 1995, 1999, 2003, 2007, 2011, 2015, 2023
- **勝利を挙げた大会**: 1987, 1991, 1999, 2003, 2007, 2015
- **プールステージ突破は一度もなし**
- **2019年日本大会のみ不出場**（下記の失格）
- RWC1995 南アフリカ戦は 8-21 で敗戦だが「スクラムで相手を上回った」と記録

## 2019年大会の失格（記事の核）
- 対象選手 **Sione Faka'osilea**。**トンガ・セブンズ代表**でのプレー歴により
  ルーマニア代表資格を欠いていた
- 制裁 **勝点30の剥奪** → 出場権喪失。**ロシアが繰り上げ出場**
- 同じ2017-18 Rugby Europe Championship をめぐり **スペイン40点減点・ベルギー30点減点**
- ⚠ **その後の因縁**: 2023年大会予選では**ルーマニア協会がスペインの選手資格を提訴する側**に回り、
  スペインが出場権剥奪 → ルーマニアが自動出場権を得た（スペイン側の資料で確認済み。
  `spain-chile.md` 参照）
