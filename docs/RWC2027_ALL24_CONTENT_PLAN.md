# RWC2027 全24カ国 コンテンツ構想（ティア2から全チームへ拡張）

策定日: 2026-07-22

## 方針
- 当初はティア2の8カ国に絞ったが、**強豪国も需要は当然ある**。RWC2027出場**全24カ国**を対象化。
- 競合は「1国1記事」で止まる。本サイトは**1国につき複数記事＋横断比較記事**で深さで勝つ。
- 独自の武器＝**master データから計算する「代表選手の所属クラブ／リーグ分布」**。
  例: フランス代表は63人中63人がTop14。日本代表はほぼ全員リーグワンD1。
  スコットランドはURC中心。これは他媒体が持っていない一次データ。

## 独自データ（C・X1・X2・X5）の作り方 — master 駆動
- `data/master/players/national.json`（代表）の各選手 slug を、
  各リーグファイル（top14 / urc / premiership / super-rugby / mlr / league-one-* 等）と突合し、
  「その代表選手がどのリーグでプレーしているか」を集計する。
- **実証済み（2026-07-22）**: france=Top14 63/63、scotland=URC中心、italy=URC/Top14分散、
  日本=リーグワンD1にほぼ集中。
- **課題**: national.json は現状フランス・イタリア・スコットランド等 all.rugby「スター収集」対象国のみ。
  フィジー・サモア・トンガ・ジョージア・アルゼンチン・ウルグアイ・NZ・南ア・アイルランド・
  イングランド・豪・ウェールズは 0 件。
  → **全24カ国の代表スカッドを all.rugby から追加収集**すれば全チームで分布が出せる
    （all.rugby は `/club/<country>/squad` で各国代表を保持。MLRと同じ手法でパイプライン拡張）。
    収集先リーグに無い所属（仏Pro D2・英Championship 等）は「その他」に寄せる。

## 実行順（推奨）
1. **日本**（A＋C）— 最大検索ボリューム。「代表の所属クラブ分布」は日本が一番刺さる
2. プールE ライバル（フランス・サモア）＝日本と同組で関心が接続
3. 残る強豪（NZ・南ア・アイルランド・イングランド・豪・アルゼンチン・ウェールズ・スコットランド・イタリア）A/B/C
4. ジョージア・ウルグアイ・トンガ A/B/C
5. 横断比較 X1〜X5（データが揃い次第）
6. 強豪の D/E/F を順次

## 運用ルール（第1弾から継続）
- カタカナ表記を全併記（SEO）。愛称は原語＋意味。
- 事実は一次情報のみ（`docs/renewal/03_VALIDATION.md`）。選手データは all.rugby 個別ページ・公式で裏取り。
- 名鑑に実在する選手だけ個別ページへ深リンク（実在者のみ・厳密一致で取り違え防止）。
- 公開は1日1本の自動ドリップ（`src/pages/news/*` の未来pubDate非表示＋日次再ビルド）。
- ハブ&スポーク＋横リンクで回遊（第1弾ハブ `tier2-nations-guide` に強豪ハブを接続）。
