# RUGBY PICKS プロジェクト憲法

このドキュメントは、プロジェクトの品質と方向性を維持するための絶対的な基準（Source of Truth）です。

## 1. デザインと美学 (Design Aesthetics)
- **コアデザイン**: ダークモード、イエローアクセント（#facc15）、力強いタイポグラフィ（font-black）を基調としたプレミアムなデザイン。
- **選手カードの標準化**:
    - アクセントカラーはイエロー（#facc15）。表示項目は「年齢」「身長」「体重」を必須とする。
    - チーム名はボーダー（border-gray-200）と背景（bg-gray-100）のボックスに配置。
- **言語表示の優先順位**:
    - 海外選手: 英語名（name_en, 全大文字）をメイン、日本語名はサブ。
    - 日本人選手: 日本語名（title）をメイン、英語名はサブ。
- **リーグ別ブランドカラー**:
    - URC: 紺 (#003366) / 水色 (#0097D7)
    - League One: 黒 (#000000) / 赤 (#E60012)
    - Top 14: 黒 (#000000) / 金 (#C5A059)
    - Super Rugby: 青 (#0055A4) / 水色 (#00A9E0)

## 2. UI/UX 改善ルール
- **レスポンシブ**: 長い名称は改行せず、フォントサイズ調整や短縮名で対応。
- **代表データ**: `代表キャップ数` から国名を抽出。国旗絵文字（FLAG_MAP）を正確に紐付ける。
- **キャリア遍歴**: 昇順（古い順）に整理。連続・重複期間は統合（例: 2020-2024）。現役は「2025 - 」。
- **回遊性**: キャリア履歴内のチーム名は詳細ページ（/teams/）へリンクさせる。

## 3. データの取り扱い (Data Source of Truth)
- **CSV至上主義**: `data_sources/final_master_data_v27_normalized.csv` を唯一の正解とする。
- **公式サイト優先**: 情報は League One, Super Rugby, Top 14, URC の公式サイトから取得。
- **自動計算**:
    - 年齢: 生年月日から動的に算出。
    - 代表キャップ: 公式プロフィールから抽出。
- **不備の扱い**: 独自判断での補完・書き換えは禁止。「不明」とせず可能な限り公式情報を調査する。
- **固有名詞**: 「Vodacom」→「ヴォーダコム」、「Harlequins」→「ハーレクインズ」を遵守。

## 4. 技術スタックと自動化 (Tech & Automation)
- **Astro + React**: 高速なページ遷移とSEOの最大化。
- **データパイプライン**: CSV更新 → `scripts/update_site.sh` 実行でサイト全体を更新。
- **ID/URLベースの重複排除**: `all.rugby` の URL を主キーとして `scripts/deduplicate_master.py` で統合。
- **クリーンアップ**: Markdown 生成前に `src/content/players/` を全削除（幽霊ページ防止）。
- **検索ロジック**: 数値（年齢・身長・体重）の検索は完全一致で処理。

## 5. 運用フロー
- **更新フロー**: CSV直接編集 → `scripts/update_site.sh` 実行。
- **自動更新**: GitHub Actions で毎週月曜午前に自動スクレイピング実行。
- **Discord連携**: 作業完了、エラー、承認が必要な場合は必ず Discord チャンネルへ報告すること。
- **SEO/収益化**: 全ページで構造化データ、メタタグ、AdSense/アフィリ配置を考慮する。
