秋の大学ラグビーは、気づくと「対抗戦」「リーグ戦」「選手権」と似た言葉が並んで、どれから見ればいいのか分からなくなりがちです。

この記事は、速報ではなく**全体像の整理**です。読み終えたときに「この大会はこういう位置づけで、この試合から見ればいい」と言える状態を目指しました。

> **データ基準日：2026年10月20日時点。** 日程・会場・放送は変更になることがあります。最新の情報は、日本ラグビーフットボール協会（JRFU）、各地域協会、各大学ラグビー部の公式サイトで必ずご確認ください。

## まず結論：大学ラグビーはこの3層で見る

先に全体の地図を置きます。細かいところは、あとで順番に説明します。

| 層 | 中身 | 役割 |
|:---|:---|:---|
| 地域リーグ | 関東（対抗戦・リーグ戦）、関西、九州ほか | 9月〜12月初めの秋のシーズン。ここで順位が決まる |
| 全国大学選手権 | 地域リーグの上位校などが集まる14チームのトーナメント | 11月下旬〜1月。日本一を決める |
| 入替戦 | 各リーグの下位と下のカテゴリーの上位が対戦 | 来季どのリーグでやるかを決める |

つまり、**秋は「選手権に出るための予選」と「残留を懸けた戦い」が同時に走っている**ということです。上位の争いと下位の争い、両方にドラマがあるのが大学ラグビーの面白さです。

## 大学ラグビーの構造（地域ごと）

### 関東：対抗戦とリーグ戦の2本立て

関東には、性格の違う2つの大きなリーグがあります。

**関東大学対抗戦（Aグループ）** は、伝統校が集まる歴史ある枠組みです。2026年度のAグループは次の8校で、総当たり（全7節・全28試合）です。

- [早稲田大学](/teams/university/waseda-university/)
- [明治大学](/teams/university/meiji-university/)
- 慶應義塾大学
- [帝京大学](/teams/university/teikyo-university/)
- 筑波大学
- 日本体育大学
- 青山学院大学
- 立教大学

2026年度は9月12日に開幕し、12月6日に最終日を迎えます。最終日には、伝統の**早明戦**（明治 対 早稲田、MUFGスタジアム＝国立競技場）を含む4試合が組まれています。

**関東大学リーグ戦（1部）** も8校の総当たりで、全7節・全28試合。2026年度は9月13日に開幕し、11月29日が最終日です。2026年度の顔ぶれは次のとおりです。

- 東海大学
- 東洋大学
- 流通経済大学
- 関東学院大学
- 立正大学
- 日本大学
- 専修大学（2部から昇格）
- 法政大学

リーグ戦1部は、**全国選手権の出場枠が3つ**あります。つまり、この8校のうち上位3校が日本一への挑戦権を得るわけです。一方で下位は2部との入替戦に回るため、**上は選手権、下は残留**という二つの争いが同時に進みます。

なお、関東にはこの下にもリーグ戦2部、対抗戦Bグループといった下位カテゴリーがあります。下位の入替戦の細かい運用や日程は、この記事では確認できた範囲だけ書き、確認できていない部分は書きません（関東ラグビー協会の発表をご確認ください）。

### 関西：Aリーグ8校の総当たり

関西は**関西大学Aリーグ**が頂点です。2026年度は次の8校が参加しています。

- 天理大学
- [京都産業大学](/teams/university/kyoto-sangyo-university/)
- 同志社大学
- 近畿大学
- 関西大学
- 摂南大学
- 関西学院大学
- 立命館大学

Aリーグは**全7節の総当たり**で、9月13日に開幕しました。最終節は11月28・29日の予定です。下位（7・8位）は、12月13日の入替戦でBリーグ側と来季の昇降格を争います。

関西の下には、Bリーグ、C1リーグ、C2リーグが続いています。2026年度はBリーグが8チーム制に変わるなど、下位の構成が再編されました。

選手権への出場枠は**上位3校**です。第62回大会では、天理大学、京都産業大学、関西学院大学が関西代表として出場しました。

### 九州・その他の地域

**九州学生ラグビーリーグ**は、2026年度は9月19日から11月29日にかけて開催されます。A〜Dの4つのリーグに分かれて戦い、上位リーグの順位決定戦を経て、**優勝校が全国選手権に出場**します（選手権への枠は九州から1校）。

そのほか、**北海道・東北地区**と**東海・北陸・中国・四国地区**には、それぞれ選手権への代表枠が1つずつあります。地域の大会を勝ち抜いた代表が、選手権の1回戦・2回戦に回ります。第62回大会では、北海道・東北の八戸学院大学、東海・北陸・中国・四国の朝日大学が出場しました。

## 全国大学選手権のしくみ

### 14チームのトーナメント

全国大学ラグビーフットボール選手権大会は、現在**14チーム**で争われます。出場枠の内訳は次のとおりです。

| 出場枠の所属 | 枠数 |
|:---|:---|
| 関東大学対抗戦グループ | 3 |
| 関東大学リーグ戦 | 3 |
| 関西大学リーグ | 3 |
| 九州学生リーグ | 1 |
| 北海道・東北地区代表 | 1 |
| 東海・北陸・中国・四国地区代表 | 1 |
| 前回決勝に進んだ2校の所属リーグ・グループへの追加枠 | 2 |

最後の「追加枠」は少し分かりにくいので補足します。前回大会の優勝校と準優勝校の所属するリーグ・グループに、枠が1つずつ上積みされる仕組みです。

たとえば**第62回大会**では、優勝の明治と準優勝の早稲田がどちらも対抗戦だったため、対抗戦は3枠＋2枠で**合計5校**（明治、筑波、早稲田、帝京、慶應義塾）が出場しました。

### 勝ち上がり方

大会の流れは、強いチームほど遅く登場するしくみです。第62回大会の例で見ると、次のようになっていました。

| 試合 | 日程 | 会場 |
|:---|:---|:---|
| 1回戦 | 2025年11月22日 | パロマ瑞穂ラグビー場（愛知） |
| 2回戦 | 2025年11月29日 | JAPAN BASE（福岡） |
| 3回戦 | 2025年12月14日 | 秩父宮ラグビー場（東京）、東大阪市花園ラグビー場（大阪） |
| 準々決勝 | 2025年12月20日 | 秩父宮ラグビー場（東京）、ヤンマースタジアム長居（大阪） |
| 準決勝 | 2026年1月2日 | MUFGスタジアム（国立競技場） |
| 決勝 | 2026年1月11日 | MUFGスタジアム（国立競技場） |

ポイントは次の3つです。

1. **1回戦は地域代表同士**（北海道・東北 対 東海・北陸・中国・四国）。その勝者が2回戦で九州代表と当たります。
2. **3回戦から関東・関西の各リーグの上位校が登場**します。このとき、同じリーグ同士は当たらないよう配置されます。
3. **有力4校は準々決勝から登場**します。これが「シード」で、対抗戦の1位と2位、関西Aリーグ1位、関東リーグ戦1位が基本です（前回大会の決勝進出校の所属によって決め方が変わります）。

また、決勝が同点の場合は、トライ数などに関わらず**両校優勝**になるのも、この大会の大きな特徴です。

## 序列の変遷：誰が強いのか

### 歴代の優勝回数

選手権は1964年度（第1回）に始まりました。優勝回数が多い大学は次のとおりです。

| 順位 | 大学 | 優勝回数 |
|:---|:---|:---|
| 1 | 早稲田大学 | 16回 |
| 2 | 明治大学 | 14回 |
| 3 | 帝京大学 | 13回 |

この上位3校で、歴史の大部分を占めます。それに続くのは、関東学院大学（6回）、同志社大学（4回）などです。

### 近年の流れ

直近10大会を並べると、勢力図の変化が見えてきます。

| 年度（回） | 優勝 | 準優勝 |
|:---|:---|:---|
| 2016（第53回） | 帝京 | 東海 |
| 2017（第54回） | 帝京 | 明治 |
| 2018（第55回） | 明治 | 天理 |
| 2019（第56回） | 早稲田 | 明治 |
| 2020（第57回） | 天理 | 早稲田 |
| 2021（第58回） | 帝京 | 明治 |
| 2022（第59回） | 帝京 | 早稲田 |
| 2023（第60回） | 帝京 | 明治 |
| 2024（第61回） | 帝京 | 早稲田 |
| 2025（第62回） | 明治 | 早稲田 |

見どころを3つ挙げます。

- **帝京大学の時代があった。** 2009〜2017年度に9連覇、2021〜2024年度に4連覇。大学ラグビーの序列を作った存在です。
- **2025年度は明治が帝京の4連覇を止めた。** 第62回決勝は明治22-10早稲田で、明治は第55回以来7大会ぶり、14回目の優勝でした。
- **直近10大会で関西勢の優勝は2020年度の天理だけ。** 関西勢は決勝に届く年もありますが、関東勢の壁が厚い傾向が続いています。

### これからの見立て（推測）

ここからは**推測**です。断定はできません。

直近は、帝京の連覇が止まり、明治、早稲田が決勝に戻ってきた形です。2026年度も、対抗戦の上位（明治、早稲田、帝京、慶應義塾あたり）が優勝争いの中心になる可能性は高そうです。一方で、関西のAリーグでは天理と京都産業が開幕から無敗で並んでおり（第4節終了時点）、関西勢が準決勝まで食い込めるかも注目点になりそうです。

もちろん、トーナメントは一発勝負です。リーグ戦の順位がそのまま結果になるとは限らない点も、大学ラグビーのおもしろさです。

## どう見るか：観戦ガイド

### 順位表の読み方

大学ラグビーの順位表には、勝敗のほかに「勝点」が載っています。勝点にはボーナス点が含まれるため、**勝ち数が同じでも勝点の差で順位が入れ替わる**ことがあります。「勝ち数だけ見て安心できない」のがポイントです。

見るべきは次の3点です。

- **選手権の出場圏内（上位3位まで）に入っているか。** 関東も関西も、ここが最初の分かれ目です。
- **シード（準々決勝からの登場）に絡む1〜2位か。** 選手権でどのくらい楽に始められるかが変わります。
- **下位は入替戦圏内か。** 関東リーグ戦、関西Aリーグとも、下位は入替戦に回ります。

### 最初に見るべき試合

「まず1試合だけ」なら、次の伝統の一戦をおすすめします。

| カード | 2026年度の日程 | 備考 |
|:---|:---|:---|
| 慶明戦（慶應義塾 対 明治） | 11月1日（日） | 対抗戦。伝統の一戦 |
| 帝京 対 早稲田 | 11月1日（日） | 同じ日に組まれた強豪同士 |
| 帝京 対 明治 | 11月22日（日） | 対抗戦の終盤の大一番 |
| 早慶戦（慶應義塾 対 早稲田） | 11月23日（月・祝） | 伝統の一戦 |
| 早明戦（早稲田 対 明治） | 12月6日（日） | 対抗戦の最終日。MUFGスタジアム（国立競技場） |

関西では、天理、京都産業、同志社といった上位校同士の試合が、選手権への道を左右します。

### 初心者向けの楽しみ方

- **応援する1校を決めて追う。** 1校の勝敗を軸にすると、順位表の見方も自然に身につきます。
- **「リーグ戦の消化試合」はない。** 下位の入替戦や、2位と3位の差（シード権）など、最終節までなにかが懸かっています。
- **リーグワンとのつながりを探す。** 大学を卒業した選手がリーグワンでプレーしています。気になる選手は[選手名鑑](/players/)や各大学の情報から、大学時代の所属を辿ると面白くなります。

## 視聴方法

視聴手段は、**J SPORTS** と **NHK**（とJRFU関連の配信）が中心です。

### J SPORTS

J SPORTSは、関東大学対抗戦、関東大学リーグ戦、関西大学リーグの試合を、放送とオンデマンドで扱っています。2026年度の対抗戦は、たとえば次のカードが放送予定に載っています（時間は変更される場合があります）。

| 日付 | カード |
|:---|:---|
| 10月24日（土） | 日本体育大 対 慶應義塾大、明治大 対 立教大 |
| 10月25日（日） | 早稲田大 対 筑波大 |
| 11月1日（日） | 帝京大 対 早稲田大、明治大 対 慶應義塾大（慶明戦） |
| 11月22日（日） | 帝京大 対 明治大 |
| 11月23日（月・祝） | 慶應義塾大 対 早稲田大（早慶戦） |

放送される試合と、ネット配信のみの試合があります。「配信コンテンツは放送番組とは異なる」と案内されているので、見たい試合が放送か配信かは、J SPORTSの番組表で確認してください。

### NHK

選手権では、NHKが共催に入っています。第62回大会（前回）の実績は次のとおりでした。

- **準々決勝**：Eテレ、NHK ONE（一部の試合は録画や別配信）
- **準決勝**：総合テレビ、NHK ONE
- **決勝**：Eテレ、NHK FM、NHK ONE

3回戦までと、関西会場の準々決勝は、J SPORTSの放送・オンデマンドが中心でした。また、準々決勝の一部の試合は、YouTubeの「JAPAN RUGBY TV」でも配信されています。

**第63回大会の放送・配信の予定は、10月20日時点では確認できていません。** 上記は前回の実績で、今季も同じ形になるかは未定です。発表されたらJRFUのお知らせに載る形が通例です。
